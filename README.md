# Zahidul Islam | Profile Portfolio

Static export prepared for https://zahidulislam-me.github.io/

1. Extract this ZIP.
2. Open the extracted Zahidul-Portfolio-Updated folder.
3. Upload its CONTENTS to the public repository zahidulislam-me.github.io. Do not upload the ZIP or outer folder. index.html must be at repository root.
4. Commit changes.
5. Settings > Pages > Deploy from a branch > main > / (root) > Save.

No installation or build required. Includes images, fonts, CV, certificates, project pages, videos and favicon. Preserve all folders and filenames.

If uploading many files is rejected, upload the small root files and work/works folders first. Then open the assets folder in GitHub and upload its contents in batches of fewer than 100 files, committing each batch.

If .nojekyll is hidden in Finder, press Command+Shift+Period to show hidden files, or create .nojekyll with Add file > Create new file.

The site's root-relative URLs are configured for your username.github.io address. Opening index.html directly from Finder is not a hosting test.
